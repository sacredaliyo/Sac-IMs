# Sacred IMS

A lightweight Python system information tool that retrieves and displays a machine's operating system details, current date and time, and installed software components.

## About
This script was developed by Aliyo Sacred during an industrial attachment at the Directorate of Government Analytical Laboratory (DGAL), Division of Questioned Documents and Computer Forensics.

## Features
- Displays the machine's Operating System details
- Displays current date and time
- Lists installed software components
- Additional system information

## Requirements
- Python 3.x

## Usage
Run the script directly:
```
python sacred_ims.py
```
